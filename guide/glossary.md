## 📚 부동산 용어 정리

### 📊 시세 관련
| 용어 | 설명 |
|---|---|
| **매매지수** | 아파트 매매가격의 변동을 지수화한 것 (2021.06 = 100) |
| **전세지수** | 아파트 전세가격의 변동을 지수화한 것 |
| **평당가** | 1평(3.3058m²)당 가격. 지역 시세 비교에 유용 |
| **전세가율** | 매매가 대비 전세가 비율. 통상 60~80% |

### 📈 분석 지표
| 용어 | 설명 |
|---|---|
| **QoQ** | Quarter over Quarter. 전분기 대비 변화율 |
| **YoY** | Year over Year. 전년 동기 대비 변화율 |
| **가속도** | 최근 3개월 상승률 - 이전 3개월 상승률 |
| **모멘텀** | 연속 상승 개월 수 |
| **핫스코어** | 여러 지표를 종합한 0~100 점수 |
| **변동성** | 시세의 불안정성. 낮을수록 안정적 |

### 🏘️ 지역 관련
| 용어 | 설명 |
|---|---|
| **GTX** | 수도권 광역급행철도. 서울 접근성을 크게 개선 |
| **뉴타운** | 구도심 재개발 방식. 주거 환경 개선 |
| **재건축** | 노후 아파트를 철거하고 새로 짓는 것 |
| **택지지구** | 정부가 계획적으로 개발하는 주거 단지 |
| **3기 신도시** | 2018년 이후 지정된 신도시 (교산, 왕숙, 대장 등) |

### ⚠️ 리스크 관련
| 용어 | 설명 |
|---|---|
| **지수 재조정** | 통계 기준시점 변경으로 모든 값이 100으로 초기화 |
| **거래 절벽** | 거래량이 급격히 감소하는 현상 |
| **조정 국면** | 상승 후 가격이 일시적으로 하락하는 시기 |
